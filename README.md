# Onde-foi-parar-meu-dinheiro-
Onde foi parar meu dinheiro? é um aplicativo mobile de consciência financeira desenvolvido em React Native. O projeto tem como objetivo auxiliar os usuários no controle e compreensão de suas despesas pessoais.

Diferentemente de um simples gerenciador financeiro, o aplicativo busca transformar os registros de gastos em informações sobre hábitos de consumo, permitindo identificar gastos não planejados, pequenas despesas acumuladas, categorias que mais comprometem o orçamento e evolução dos gastos ao longo do tempo.

O aplicativo também permitirá a criação de metas financeiras e, futuramente, desafios de economia, buscando incentivar o usuário a desenvolver hábitos financeiros mais conscientes.
